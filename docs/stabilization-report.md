## ۶. ادامه کار پس از دریافت سورس

۱. ثبت SHA دقیق سورس مبنا، دستورهای رسمی بیلد و تست و نسخه‌های مورد نیاز toolchain.
۲. نصب وابستگی‌ها مطابق manifest و lockfile واقعی پروژه؛ اجرای بیلد و تمام تست‌های موجود و ثبت خروجی و exit code.
۳. بررسی مسیرهای Lexer، Parser، Binder، Type Checker و Emitter و ثبت هر باگ با ورودی حداقلی قابل بازتولید و اولویت مشخص.

۵. پیاده‌سازی Smoke Test با ماژول‌های مرتبط شامل کلاس، اینترفیس و جنریک؛ کامپایل با همین U-TypeScript و بررسی اجرای JavaScript و نتیجه مورد انتظار، نه صرفاً exit code کامپایل.
۶. پوشش فایل خالی، ورودی نامعتبر، syntax قدیمی پشتیبانی‌شده، وابستگی چرخه‌ای و تایپ‌های تو در تو مطابق قرارداد واقعی پروژه.
۷. اجرای مجدد تمام تست‌ها و گزارش تعداد واقعی پاس/فیل/اسکیپ و محدودیت‌های محیط؛ هیچ تست اسکیپ‌شده یا اجرا‌نشده‌ای به عنوان تست پاس‌شده شمرده نمی‌شود.
۸. ثبت فیکس‌های تأییدشده با کامیت‌های اتمیک Conventional Commits و push بدون force به برنچ درخواستی.
